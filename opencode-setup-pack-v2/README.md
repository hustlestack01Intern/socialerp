# OpenCode setup pack v2
Unzip into the root of an empty repo (keep the .opencode folder). Then follow docs/KICKOFF.md.
Contents: AGENTS.md (lean working rules), docs/SPEC.md (full spec with MVP cut), docs/CONSTITUTION.md (engineering principles, stop rules, bounded self-improvement), docs/ROADMAP_90_DAYS.md, 10 agents and 8 commands in .opencode/, scripts/verify_pack.py (self-check).
If your OpenCode version uses .opencode/agent (singular) instead of .opencode/agents, rename the folders.
